# Smm-tg-bot

Telegram-бот, который раз в 2 дня сам собирает новости из источников,
переписывает их в готовый пост (текст + AI-картинка) или в опрос, отправляет
черновик админу на модерацию и публикует в канал после одобрения.

## Источники

- **buxgalter.uz** — HTML-скрапинг страницы новостей (RSS отсутствует).
- **my.soliq.uz** — используется внутренний JSON API сайта
  (`/api/main-api/news/search`), обнаруженный через анализ сетевых запросов.
- **Telegram-каналы** `soliqnews`, `uz_buxgalter`, `bank_kuni` — читаются через
  Telethon (см. ниже, почему обычный Bot API для этого не подходит).

## Как это работает

1. Планировщик (APScheduler) раз в `interval_days` дней в `time` (по
   `timezone` из `config.yaml`) запускает пайплайн.
2. Пайплайн собирает свежие элементы из всех источников, отбрасывает уже
   виденные (дедупликация в SQLite), берёт самый новый.
3. Claude переписывает новость в пост (или, если по счётчику подошла очередь
   `poll_every_n_posts`, формулирует опрос).
4. Для постов OpenAI (`gpt-image-1`) генерирует картинку.
5. Черновик уходит в чат модерации с кнопками «Опубликовать» / «Отклонить».
6. После одобрения бот публикует пост (фото + подпись) или нативный опрос в
   `TARGET_CHANNEL_ID`.

Команды в чате модерации:
- `/now` — прямо сейчас собрать новости и подготовить черновик поста.
- `/poll` — прямо сейчас подготовить опрос по последней новости.
- `/status` — последние 10 черновиков и их статус.

## Установка

### 1. Секреты

```bash
cp .env.example .env
```

Заполните `.env`:

- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather).
- `MODERATION_CHAT_ID` — chat_id, куда будут приходить черновики на
  модерацию (можно узнать, написав боту и посмотрев апдейт через
  `getUpdates`, либо через [@userinfobot](https://t.me/userinfobot) для
  личного чата).
- `TARGET_CHANNEL_ID` — канал публикации (`@my_channel` или `-100...`).
  **Бота нужно добавить в канал администратором** с правом публикации постов.
- `TELEGRAM_API_ID` / `TELEGRAM_API_HASH` — с https://my.telegram.org →
  "API development tools". Нужны, потому что обычный Bot API не даёт читать
  историю чужих публичных каналов — только Telethon-юзербот (вход под вашим
  личным аккаунтом) может это делать. Как получить:
  1. Откройте https://my.telegram.org, введите номер телефона аккаунта,
     под которым будет работать юзербот, введите код из Telegram.
  2. Зайдите в раздел **API development tools**.
  3. Откроется форма **Create new application** — это регистрация вашего
     скрипта как приложения, использующего Telegram API, реальные значения
     почти не важны (Telegram не проверяет их и не публикует нигде), но
     поля обязательны:
     - **App title** — произвольное имя, например `Smm News Bot`.
     - **Short name** — короткий идентификатор без пробелов, например
       `smm_news_bot` (5–32 символа, только буквы/цифры/подчёркивания).
     - **URL** — можно оставить пустым или указать `https://t.me/ваш_бот`.
     - **Platform** — выберите `Desktop` (ближе всего к серверному скрипту;
       на функциональность не влияет).
     - **Description** — необязательно, например `Personal news bot for my channel`.
  4. Нажмите **Create application** — на той же странице появятся
     `App api_id` (число) и `App api_hash` (строка из букв/цифр). Их и
     впишите в `.env` как `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.
- `TELEGRAM_PHONE` — номер телефона того аккаунта, под которым войдёт
  юзербот (можно завести отдельный аккаунт, не обязательно основной),
  в международном формате, например `+998901234567`.
- `ANTHROPIC_API_KEY` — ключ Claude (переписывание новостей, генерация
  опросов).
- `OPENAI_API_KEY` — ключ OpenAI (генерация картинок `gpt-image-1`).

### 2. Источники и расписание

Отредактируйте `config.yaml` при необходимости — списки источников уже
заполнены (buxgalter.uz, my.soliq.uz, 3 Telegram-канала), расписание по
умолчанию: раз в 2 дня в 10:00 по Asia/Tashkent.

### 3. Один раз — вход Telethon-юзербота

Это единственный шаг, который нельзя автоматизировать (Telegram присылает
код подтверждения на телефон), поэтому его нужно выполнить вручную из
терминала:

```bash
pip install -r requirements.txt
python scripts/telethon_login.py
```

Введите код из Telegram (и пароль 2FA, если он включён). После этого в
`data/` появится файл сессии, и бот сможет читать каналы без повторного
входа.

### 4. Запуск

**Через Docker (рекомендуется для VPS):**

```bash
docker compose up -d --build
```

`data/` монтируется как volume — там лежат SQLite-база, сгенерированные
картинки и файл сессии Telethon, так что при пересборке контейнера ничего не
теряется.

**Локально без Docker:**

```bash
pip install -r requirements.txt
python -m bot.main
```

## Структура проекта

```
bot/
  config.py             # загрузка .env + config.yaml
  db.py                 # SQLite: дедупликация, черновики
  sources/
    buxgalter.py         # скрапинг buxgalter.uz
    soliq.py              # клиент JSON API my.soliq.uz
    telegram_channels.py  # чтение Telegram-каналов через Telethon
  ai/
    text.py               # Claude: рерайт новости в пост / генерация опроса
    image.py               # OpenAI: генерация картинки
  pipeline.py            # оркестрация: источники -> AI -> черновик
  moderation.py           # отправка на модерацию, кнопки, публикация
  scheduler.py             # APScheduler job раз в N дней
  handlers/admin.py         # /now, /poll, /status
  main.py                    # точка входа
scripts/telethon_login.py   # разовый интерактивный вход юзербота
```

## Добавление нового источника

1. Добавить функцию `fetch(...)`, возвращающую `list[NewsItem]`
   (`bot/sources/base.py`), в `bot/sources/`.
2. Подключить её в `bot/pipeline.py::collect_candidates`.
3. Добавить источник в `config.yaml`.
